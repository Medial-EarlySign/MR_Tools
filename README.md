## Overview

Tools that Utilize MES Infrastructure. 
The tools are written in python and C++  and uses [medpython](https://github.com/Medial-EarlySign/medpython) libraries.

## Setup
To install the python module:
```bash
pip install medpython-etl
```

Build from source:
```bash
python -m pip install -v "MR_Tools @ git+https://github.com/Medial-EarlySign/MR_Tools.git/#subdirectory=RepoLoadUtils/common"
```

To explore the code:

* `RepoLoadUtils/common` - The python module.
